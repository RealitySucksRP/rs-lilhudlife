DRIVER SYSTEM

Vehicle HUD settings share the main speedometer position, scale and unit controls. Use Layout for placement and Speedometer for style.

NOS BOOST SYSTEM

The NOS controls remain visible in the right-side control module so you can change display style and warning level while reviewing every tab.

HUDLife reads the active NOS state from RS LS Customs and shows availability, cooldown and warning information.
