RS HUDLife - Optional Vehicle Art
=================================

HUDLife does not require a vehicle-image pack. When a matching image is absent,
boot.js and speedo.js render a built-in vehicle-class silhouette automatically.

Private/local artwork convention:

    html/assets/vehicles/<spawncode>.png
    html/assets/vehicles/<spawncode>.webp

Use the GTA/FiveM vehicle spawn code as the filename. Example: `adder.png`.

PUBLIC DISTRIBUTION
-------------------
Only redistribute images you created yourself or have permission to distribute.
Do not assume that an image being viewable on a documentation/reference website
gives you redistribution rights.

This release includes the creator's curated per-vehicle image library. Matching
spawn-code art is preferred; the built-in silhouette remains only as a fallback
for vehicles that do not have a matching image.

If you add or replace artwork, use assets you created or have permission to
redistribute. PNG and WEBP files are both included by the fxmanifest globs.
