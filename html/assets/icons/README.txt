RS HUDLife Custom Status Icons

The HUD automatically loads these files when present:

  health.png  = heart in hand
  armor.png   = bulletproof vest
  hunger.png  = hamburger
  thirst.png  = water bottle
  stamina.png = purple air / wind
  oxygen.png  = lungs (standalone underwater ring)
  nos-bottle-v128.png = active NOS / nitrous bottle (cache-safe filename)
  nos.png              = legacy fallback copy

These exact user-supplied PNG files are included in v1.2.5.
They override the built-in SVG art while preserving live ring values,
colors, low-value effects, scale controls, and F9 visibility toggles.

Keep filenames and PNG transparency unchanged when replacing artwork.
Recommended source size: 100x100 or larger square transparent PNG.

The all-in-one Survival Cluster uses stamina, health, armor, hunger, thirst, and NOS.
